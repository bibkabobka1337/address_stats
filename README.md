# address-stats

Практическое задание 3. Консольная программа для работы с CSV и XML файлами-справочниками городов.

Язык: Java 17+. Внешних библиотек нет.

## Сборка и запуск

Через Maven:

    mvn package
    java -jar target/address-stats-1.0.jar

Без Maven:

    mkdir out
    javac -encoding UTF-8 -d out $(find src -name '*.java')
    java -cp out addressbook.Main

## Использование

После запуска программа ждёт путь до файла-справочника (`.csv` или `.xml`).
Для завершения работы введите `exit` или нажмите Ctrl+D (Ctrl+Z в Windows).

Для каждого файла выводится:

1. дублирующиеся записи с количеством повторений;
2. количество 1, 2, 3, 4 и 5 этажных зданий в каждом городе (одинаковые записи считаются одним зданием);
3. время обработки файла.

Ошибки (файл не найден, неподдерживаемый формат, некорректные данные) не завершают программу.

## Структура

| Пакет | Назначение |
|-------|------------|
| `addressbook.model` | модель записи `AddressRecord` |
| `addressbook.parser` | интерфейс `AddressParser`, реализации `CsvAddressParser` и `XmlAddressParser`, `AddressParserFactory` |
| `addressbook.stats` | подсчёт статистики и сервис обработки файла |
| `addressbook.console` | цикл взаимодействия с пользователем и вывод отчёта |

Формат файла выбирается по расширению через `AddressParserFactory`; для нового формата достаточно реализовать `AddressParser` и зарегистрировать его в фабрике.
